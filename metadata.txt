about=公共測量で使用されるDMファイル（日本の数値地図フォーマット）をGeoPackage形式に変換するQGISプラグインです。単一ファイルの変換に加えて、フォルダを指定した一括変換にも対応し、JGD2011平面直角座標系を自動判定します。面・線・円・円弧・点・方向・注記（E1〜E7）の各要素タイプに対応しています。 This QGIS plugin converts DM files to GeoPackage. DM is a Japanese digital mapping format used in public surveys. It can convert a single file or all files in a selected folder, and it automatically detects the appropriate JGD2011 plane rectangular coordinate system. It supports all element types from E1 through E7, including areas, lines, circles, arcs, points, directions, and annotations.
