
【ソフトウェアについて】

　○　動作環境
　　・このソフトウェアは，Microsoft(R) Windows(R) 上で動作します。
  　  Microsoft(R) Windows(R) 8.1,Windows(R) 10,Windows(R) 11において動作確認を行っております。
　　・このソフトウェアは，公共測量成果等を読み込んで，閲覧・簡易検査・フォーマット変換することを目的としています。
　　・機能等の詳細は，操作説明書またはヘルプを参照してください。
