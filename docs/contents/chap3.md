# 仕様リファレンス

## QMLスタイルファイルの準備

スタイルフォルダには、ジオメトリタイプ（点・線）ごとに 1 つずつ、QMLファイルを配置します。ファイル名は任意です。ジオメトリタイプはファイル名ではなく QMLファイルの内容から自動的に判定されます。

### QMLファイルの要件

| 項目 | 要件 |
|---|---|
| レンダラー | カテゴリ分け（categorizedSymbol） |
| 分類フィールド | `HCODE2`（分類コード 4 桁 + 図形区分の文字列） |

`HCODE2` フィールドは変換後の GeoPackageに含まれる属性フィールドです。このフィールドでカテゴリ分けされていない QMLファイルはスタイルとして適用されません。


### QMLファイルの作成方法

1. QGIS で変換済みの GeoPackage を開く
2. レイヤプロパティ → シンボロジーで `HCODE2` フィールドを使ったカテゴリ分けスタイルを設定する
3. レイヤプロパティ下部の「スタイル」→「スタイルを保存」→「QMLファイルとして保存」を選択する
4. 点・線・面それぞれのレイヤに対して上記手順を繰り返し、同一フォルダに保存する

## 出力データの仕様

### レイヤ構成

変換後の GeoPackage は要素タイプ・分類コードごとにレイヤが分割されます。各レイヤのジオメトリタイプは以下のとおりです。

| 要素タイプ | 内容 | ジオメトリタイプ |
|---|---|---|
| E1 | 面 | Polygon |
| E2 | 線 | LineString |
| E3 | 円 | Polygon |
| E4 | 円弧 | LineString |
| E5 | 点 | Point |
| E6 | 方向 | Point |
| E7 | 注記 | Point |


### 属性フィールド

**共通フィールド（全レイヤ）**

| フィールド名 | 型 |
|---|---|
| レコードタイプ | 文字列 |
| 分類コード | 文字列 |
| 地域分類 | 整数 |
| 情報分類 | 整数 |
| 要素識別番号 | 整数 |
| 階層レベル | 整数 |
| 図形区分 | 整数 |
| 実データ区分 | 整数 |
| 精度区分 | 整数 |
| 注記区分 | 整数 |
| 転位区分 | 整数 |
| 間断区分 | 整数 |
| 属性数値 | 整数 |
| 属性区分 | 整数 |
| 取得年月 | 文字列 |
| 更新取得年月 | 文字列 |
| 消去年月 | 文字列 |


**E7 注記レイヤ固有フィールド**

| フィールド名 | 型 |
|---|---|
| 注記内容 | 文字列 |
| 縦横区分 | 整数 |
| 字の大きさ | 整数 |
| 字隔 | 整数 |
| 文字列の方向 | 整数 |
| 線号 | 整数 |


**E6 方向レイヤ固有フィールド**

| フィールド名 | 型 |
|---|---|
| 方向角 | 実数 |
