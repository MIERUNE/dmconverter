# 警告・エラーメッセージ

処理パネルに表示される主なエラー・警告メッセージと、その原因および対処方法を説明します。

## DMファイルをGeoPackageに変換

### 入力に関するエラー

| メッセージ | 原因 | 対処方法 |
|---|---|---|
| DMファイルまたはフォルダを指定してください | 「入力：DMファイル」と「入力：DMファイルが格納されたフォルダ」がどちらも未入力 | いずれか一方を指定してください |
| フォルダ内にDMファイルが見つかりません | 指定したフォルダに `.dm` ファイルが存在しない | フォルダの中身を確認してください |
| 読み込みに失敗したためスキップ: {ファイル名} | ファイルが破損しているか、非対応のフォーマット | 対象ファイルの内容を確認してください |
<br>

### ファイルのスキップに関するエラー

フォルダを指定して複数ファイルを変換する場合、最初に読み込まれたファイルの座標系・地図情報レベルが基準になります。基準と異なるファイルはスキップされます。

| メッセージ | 原因 | 対処方法 |
|---|---|---|
| 座標系が異なるためスキップ（基準: 座標系{番号}）: {ファイル名} | フォルダ内のファイルで座標系番号が混在している | 同じ座標系のファイルをまとめて別フォルダに分けてから変換してください |
| 地図情報レベルが異なるためスキップ（基準: {レベル}）: {ファイル名} | フォルダ内のファイルで地図情報レベルが混在している | 同じ地図情報レベルのファイルをまとめて別フォルダに分けてから変換してください |
| 変換可能なDMファイルがありません | すべてのファイルがスキップされた | エラー内容を確認し、変換対象ファイルを見直してください |
<br>

### 変換結果に関する警告

以下のメッセージが表示された場合、変換自体は完了していますが、一部の要素が変換されていない可能性があります。

| メッセージ | 内容 |
|---|---|
| 未対応の要素タイプ: {タイプ} | E8（属性）など、現バージョンで未対応のタイプが含まれていた。該当要素は変換されません |
| コード表に未定義の分類コード: {コード} | 定義されていない分類コードが含まれていた。該当要素は変換されますが、スタイルが適用されません |
<br>

## スタイルを適用してQLRを出力

| メッセージ | 原因 | 対処方法 |
|---|---|---|
| スタイルフォルダを指定してください | 「入力：スタイルフォルダ（QML）」が未入力 | スタイルフォルダを指定してください |
| スタイルフォルダが見つかりません: {パス} | 指定したフォルダが存在しない | フォルダのパスを確認してください |
| フォルダ内にGeoPackageファイルが見つかりません | 指定したフォルダに `.gpkg` ファイルが存在しない | フォルダの中身を確認してください |
| QMLの解析に失敗（スキップ）: {ファイル名} | QMLファイルが破損しているか、非対応の形式 | QMLファイルの内容を確認してください |
| QML読み込み失敗: {ファイル名} | QMLファイルの読み込みエラー | QMLファイルのパスと内容を確認してください |
| QLRエクスポート失敗 | 出力先への書き込みができなかった | 出力先フォルダの書き込み権限を確認してください |
