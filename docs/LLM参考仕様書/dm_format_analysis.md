## 1. DMファイル構造概要

### 1.1 基本情報

- **レコード長**: 固定84バイト
- **フォーマット**: テキストベース
- **エンコーディング**: 
  - 半角文字（レコードタイプ、コード等）: ASCII
  - 全角文字（属性、注記等）: Shift-JIS
- **改行コード**: CR+LF（`\r\n`）

### 1.2 ファイル構成

```
[図郭レコード M]  ← ファイルメタ情報・座標系
  [要素グループ G] ← 分類コード（1100境界、2100道路等）
    [要素レコード E] ← 個別地物の属性
      [実データ R]   ← 座標データ（複数）
      [実データ R]
      ...
    [要素レコード E]
      ...
  [要素グループ G]
    ...
[図郭レコード M]  ← 次の図郭（複数図郭の場合）
  ...
```

### 1.3 座標系と単位

- **座標系**: 平面直角座標系（19系統）
- **座標単位**: ミリメートル（mm） → 実装時にメートル（m）へ変換が必要
- **EPSG対応**: 
  - 系番号01 → EPSG:6669
  - 系番号02 → EPSG:6670
  - ...
  - 系番号19 → EPSG:6687

**役割**: ファイル全体のメタデータ、座標系情報を格納

**重要フィールド**:
- 図郭識別番号（先頭2桁が座標系番号）
- 測地成果（JGD2000/2011）
- バウンディングボックス（図郭範囲）

**実装時の注意**:
- 座標値は**ミリメートル単位**で格納 → メートルに変換（÷1000）
- 座標系番号からEPSGコードを導出: `EPSG:666{8+座標系番号}`

### 3.2 要素グループヘッダレコード（G）

**役割**: 同一分類コードの地物をグループ化

**重要フィールド**:
- 分類コード（4桁）
- グループ内要素数

**実装時の注意**:
- 分類コードが**レイヤー分割の基準**
- 同一分類コードの地物は同一GeoPackageレイヤーに格納

### 3.3 要素レコード（E1-E8）

**役割**: 個別地物の属性とジオメトリタイプを定義

**ジオメトリタイプ対応**:

| Eタイプ | ジオメトリ | GeoPackage出力 |
|---|---|---|
| E1 | 点 | Point |
| E2 | 線 | LineString |
| E3 | 面 | Polygon |
| E4 | 方向付き点 | Point（rotation属性追加） |
| E5 | 円 | Polygon（36頂点の多角形近似） |
| E6 | 円弧 | LineString（線分近似） |
| E7 | 楕円 | Polygon（多角形近似） |
| E8 | 穴あき多角形 | Polygon（内側リング対応） |

**実装時の注意**:
- 代表点座標は**必須フィールド**（座標データがない場合のフォールバック）
- 属性データ（43-84バイト）は**Shift-JISでデコード**

### 3.4 実データレコード（R）

**役割**: 地物の座標データを格納

**構造**:
- 1レコード = 1座標点（X, Y, Z）
- 複数のRレコードで線・面を構成

**実装時の注意**:
- 座標値は**ミリメートル単位** → メートルに変換
- Z座標（標高）は**オプション**（未入力の場合は0または空）
- 面ジオメトリは**始点と終点を一致させる**（閉じた多角形）

### 4.3 分類コードマッピング

```python
# @DmLayerNameList.txtから分類コード辞書を作成
def load_layer_names(filepath: str) -> dict:
    layer_names = {}
    with open(filepath, 'rb') as f:
        for line in f:
            decoded = line.decode('shift_jis').strip()
            if decoded and not decoded.startswith('#'):
                parts = decoded.split(',')
                if len(parts) == 2:
                    code, name = parts
                    layer_names[code] = name
    return layer_names
```

### 4.4 エラーハンドリング

**想定されるエラー**:
1. **Shift-JIS デコードエラー**: `errors='replace'` で代替文字に置換
2. **レコード長不足**: 84バイト未満のレコードはスキップ
3. **数値変換エラー**: フィールドが空白の場合のデフォルト値設定
4. **EOF マーカー**: `0x1A` で終了

**エラーハンドリング例**:
```python
try:
    value = int(line[10:18])
except ValueError:
    value = 0  # デフォルト値
```
